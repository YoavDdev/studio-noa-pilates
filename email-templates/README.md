# 📧 תבניות מיילים - Supabase

תבניות מיילים מותאמות אישית לסטודיו נועה פילאטיס.

## 📝 הוראות התקנה

### 1️⃣ תקן את Site URL (חובה!)

1. לך ל-[Supabase Dashboard](https://app.supabase.com)
2. בחר את הפרויקט שלך
3. **Settings** → **API**
4. גלול למטה ל-**Site URL**
5. שנה מ-`http://localhost:3000` ל-`https://studio-noa-pilates.vercel.app`
6. **Save**

---

### 2️⃣ העתק תבניות מיילים

#### תבנית 1: Confirm Signup (אישור הרשמה)

1. לך ל-**Authentication** → **Email Templates**
2. לחץ על **Confirm signup**
3. **מחק** את כל ה-HTML הקיים
4. פתח את `confirm-signup.html`
5. **העתק הכל** והדבק ב-Supabase
6. **Save**

#### תבנית 2: Reset Password (איפוס סיסמה)

1. לחץ על **Reset Password** בתפריט
2. **מחק** את כל ה-HTML הקיים
3. פתח את `reset-password.html`
4. **העתק הכל** והדבק ב-Supabase
5. **Save**

---

## 🎨 עיצוב התבניות

התבניות כוללות:

✅ **עיצוב עקבי** עם האתר (צבעים, פונטים)
✅ **RTL** מלא לעברית
✅ **רספונסיבי** לכל המכשירים
✅ **נקי ומינימלי** - editorial style
